Bölmə 00

Kotlin nədir?

Kotlin — JetBrains tərəfindən hazırlanmış, statik tipli, müasir proqramlaşdırma dilidir. O, JVM (Java Virtual Machine) üzərində işləyir, həmçinin JavaScript, native maşın koduna və WebAssembly-yə kompilyasiya oluna bilir.

Kotlin-in yaranma səbəbi sadədir: JetBrains öz məhsullarını (IntelliJ IDEA və s.) Java ilə yazırdı və Java-nın verbosluğu, null xətaları, köhnə tip sistemi onları yorurdu. Mövcud alternativlər (Scala, Groovy) ya çox mürəkkəb, ya da çox yavaş kompilyasiya olunurdu. Nəticədə öz dillərini yaratdılar — praktik, Java ilə 100% uyğun və qısa.

Kotlin-i fərqləndirən 6 xüsusiyyət

🛡️

Null təhlükəsizliyi

Tip sistemi null dəyəri olan və olmayan tipləri ayırır. «Milyard dollarlıq səhv» kompilyasiya vaxtı tutulur, istifadəçinin telefonunda yox.

✂️

Az kod, çox iş

Eyni funksionallıq Java ilə müqayisədə orta hesabla 30–40% az sətir tələb edir. data class bir sətirdə 5 metod yaradır.

🤝

Java ilə tam uyğunluq

Eyni layihədə Java və Kotlin faylları yan-yana yaşaya bilər. Mövcud Java kitabxanalarının hamısı işləyir — heç nə yenidən yazılmır.

⚡

Coroutine-lər

Asinxron kodu sinxron kod kimi yazmaq imkanı. Minlərlə eyni vaxtlı əməliyyat thread yaratmadan idarə olunur.

🌍

Multiplatform

Bir biznes məntiqi — Android, iOS, desktop, backend və web. Yalnız interfeys hissəsi platformaya xas yazılır.

📈

Sənaye dəstəyi

Google Android üçün «Kotlin-first» elan edib. Netflix, Uber, Pinterest, Trello, Duolingo istehsalatda istifadə edir.

val və var

    

      

        

        Deyisenler.kt
        

          
          
        

      


fun main() {
    // val — yalnız oxunan (read-only), yenidən təyin edilə bilməz
    val ad = "Aysel"
    // ad = "Leyla"        ← KOMPİLYASİYA XƏTASI

    // var — dəyişdirilə bilər
    var sayqac = 0
    println("Ad: $ad")
    println("Sayqac: $sayqac")
    sayqac++
    println("Sayqac: $sayqac")

    // DİQQƏT: val referansı sabitləyir, obyektin özünü YOX

Yüksək sıralı funksiya (higher-order function) — parametr kimi funksiya qəbul edən və ya funksiya qaytaran funksiyadır. Lambda isə adı olmayan funksiyadır. Bu ikisi Kotlin-in ən güclü tərəfidir.

fun main() {
    // Tam forma: { parametrlər -> gövdə }
    val topla: (Int, Int) -> Int = { a, b -> a + b }
    println(topla(5, 3))

    // Tip açıq yazılanda parametr tipləri lazım deyil
    val topla2 = { a: Int, b: Int -> a + b }
    println(topla2(5, 3))

        val prefix = "Salam"
        "$prefix $ad"
    }
    println(salamla("Aysel"))
}

import kotlinx.serialization.Serializable

@Serializable
data class Istifadeci(val id: Int, val ad: String, val email: String)

val baza = mutableListOf(
    Istifadeci(1, "Aysel", "aysel@mail.az"),
    Istifadeci(2, "Kamran", "kamran@mail.az")
)

fun main() {
    embeddedServer(Netty, port = 8080) {
        install(ContentNegotiation) { json() }

        routing {
            get("/istifadeciler") {
                call.respond(baza)
            }

            get("/istifadeciler/{id}") {
                val id = call.parameters["id"]?.toIntOrNull()
                    ?: return@get call.respond(HttpStatusCode.BadRequest, "Yanlış id")

                val istifadeci = baza.find { it.id == id }
                    ?: return@get call.respond(HttpStatusCode.NotFound, "Tapılmadı")

                call.respond(istifadeci)
            }

            post("/istifadeciler") {
                val yeni = call.receive<Istifadeci>()
                baza.add(yeni)
                call.respond(HttpStatusCode.Created, yeni)
            }

            delete("/istifadeciler/{id}") {
                val id = call.parameters["id"]?.toIntOrNull()
                val silindi = baza.removeIf { it.id == id }
                call.respond(if (silindi) HttpStatusCode.NoContent else HttpStatusCode.NotFound)
            }
        }
    }.start(wait = true)
}

Tez-tez verilən suallar


    
Kotlin öyrənmək üçün əvvəlcə Java bilmək lazımdırmı?

    
Xeyr. Kotlin-i birinci dil kimi öyrənmək tamamilə mümkündür və bir çox hallarda daha rahatdır — daha az boilerplate, daha aydın xəta mesajları. Java biliyi yalnız köhnə kitabxanaları oxuyanda kömək edir.


    
Kotlin Java-nı əvəz edəcəkmi?

    
Android-də praktiki olaraq artıq edib. Backend-də isə Java hələ də dominantdır və uzun müddət qalacaq. İkisi rəqib deyil — eyni platformada birlikdə yaşayırlar.


    
Kotlin yavaşdırmı?

    
Xeyr. Eyni bayt-koda kompilyasiya olunur və performans Java ilə praktiki olaraq eynidir. Kompilyasiya vaxtı əvvəllər yavaş idi, K2 kompilyatoru ilə bu problem həll olundu.


    
Coroutine-ləri nə vaxt öyrənməliyəm?

    
Dilin təməlini (siniflər, kolleksiyalar, lambda) mənimsədikdən sonra. Coroutine mürəkkəb mövzudur və əsasları bilmədən öyrənmək çətindir. Amma Android yazacaqsansa, ona mütləq çatacaqsan.


    
Hansı IDE?

    
IntelliJ IDEA Community (pulsuz) — ümumi Kotlin üçün. Android Studio — Android üçün. Fleet — KMP üçün. VS Code Kotlin dəstəyi zəifdir, tövsiyə olunmur.
